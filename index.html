How it works

Start with one random five-digit stroke target. That is the total you need to work through before release is permitted. Instead of simply counting down, progress is earned through randomly selected tasks. Each round chooses a main category, then a task and its relevant parameters. Complete the task to continue and, when the selected task is a Stroke task, add those completed strokes toward the overall goal.

The six main task categories are:

  • Stroke — stroke challenges with a randomly selected amount and tempo.
  • Anal — randomly selected anal tasks with their own size, time or tempo parameters.
  • Service — service tasks such as Waiter, Masseur and Human Furniture.
  • Clean — one cleaning method combined with a randomly selected room.
  • Torture — Cock/Ball, Ass or Nipple subcategories with independently randomized parameters.
  • Position — cage, slave-position or bondage tasks with the relevant position, accessories and time.
Release rule

Release is not permitted while working toward the target, including during a Stroke task. If you get too close, pause the Stroke task before going any further. Pausing is allowed, but it triggers the app’s pause consequence before progress can continue.

If release happens anyway, it must be treated as a ruined result in the app. The ruined-result consequence then applies and the stroke target is recalculated according to the rules.

Your current target, progress, task results and ongoing consequences are cached locally and, when signed in, synchronized to your private cloud state.
